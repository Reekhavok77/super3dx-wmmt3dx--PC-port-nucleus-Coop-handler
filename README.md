# super3dx/wmmt3dx+-PC-port-nucleus-Coop-handler
A simple handler for super3dx,for multiple display, 4 player max

A custom [Nucleus Co-op](https://www.splitscreen.me/) split-screen handler for **Super3DX+** (*Wangan Midnight Maximum Tune 3DX+* native PC port). Play up to 4-player local split-screen on a single PC using any combination of controllers and keyboards.

Download

## Tutorial
1. Download the handler on releases
2. Drag the .js file to Nucleus Coop ui
3. setup the display you want
4. after starting the game go to Versus>Lan and make a lobby, same with other players
5. ready and start and have fun
